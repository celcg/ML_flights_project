# Reports

Generated project outputs are grouped by purpose:

- `eda/`: exploratory data profiling and diagnostic figures.
- `business/analysis/`: final aggregated business analysis.
- `business/report_assets/`: figures and tables used in the descriptive report and dashboard.
- `data_quality/expanded/`: ingestion, schema, null-quality and split checks for the expanded dataset.
- `modeling/expanded/`: current model selection, evaluation metrics and predictions.
- `modeling/legacy/`: retained baselines and earlier experiments used for comparison.

Temporary smoke tests, preflight notebooks, execution logs and superseded benchmark outputs are not retained here.
